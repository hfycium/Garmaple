# Garmaple

把 Garmin 手表的数据变成 AI 可查询、可分析的本地知识库。

## 为什么是"本地数据"路线

佳明中国区账号（`connect.garmin.cn`）与国际区（`connect.garmin.com`）是两套完全隔离的服务器：

- 国际区已开放官方 Personal API（2026-10 重开，免费自助、只读）
- 中国区 `personal.connectapi.garmin.cn` 域名已预留但后端未投产（实测返回 Cloudflare 526）
- 逆向 `sso.garmin.cn` 可行但违反 ToS，有封号风险

因此本项目走第三条路：**使用佳明官方"导出您的数据"功能拿到的完整归档**。这是账号自带的功能，合规、零风险、字段比官方 API 更全（官方 API 会剥离 VO2max、恢复时间、performance condition 等字段）。

## 数据来源

在 `connect.garmin.cn` 账户管理中心发起"导出您的数据"，邮件会收到一个 zip，解压后放入 `data/`：

```
data/
└── <导出的数据包>.zip
    ├── DI_CONNECT/DI-Connect-Fitness/      # 活动摘要、个人最佳、训练计划
    ├── DI_CONNECT/DI-Connect-Wellness/     # 睡眠、生物指标、异常心率
    ├── DI_CONNECT/DI-Connect-Metrics/      # 训练历史、最大摄氧量、赛事预测
    ├── DI_CONNECT/DI-Connect-Aggregator/   # 每日汇总（UDS）、饮水记录
    ├── DI_CONNECT/DI-Connect-Uploaded-Files/
    │   └── UploadedFiles_0-_Part1.zip      # 全部原始 .fit（数千个）
    └── customer_data/                      # 账户资料
```

原始数据**不入版本库**（见 `.gitignore`）。

## 目录约定

| 路径 | 用途 | 是否入库 |
|---|---|---|
| `data/` | 佳明导出原始包 | 否 |
| `cache/` | 解析后的索引（SQLite） | 否 |
| `out/` | 生成的运动课表 `.fit` | 否 |
| `garmaple/` | 主代码 | 是 |
| `tests/` | 测试与合成样本 | 是 |

## 数据安全

### 工具本身

**只读本地文件、不联网、不上传、不调用任何远端接口。** 没有遥测、没有统计上报、没有云端同步。解析、索引、查询全部在你自己的机器上完成。

`data/` 与 `cache/` 被 `.gitignore` 排除，防止原始数据或索引被误提交。

### 但"工具不联网"不等于"数据不出本机"

这一点必须写清楚，否则是虚假承诺。数据链路是：

```
磁盘上的 .fit / .json
      │  解析（本机）
      ▼
   本地索引（SQLite）
      │  工具调用（本机）
      ▼
  MCP 返回值 ─────────► AI 上下文 ─────────► 模型服务商服务器
                   ↑
             真正的数据边界在这里
```

工具不联网，但**工具返回的内容会被 AI 读取，随后发送给模型服务商**。所以外泄面不在文件解析环节，而在工具输出环节。

### 因此：脱敏发生在工具层

原则是**聚合优先、默认粗化**——尽可能返回统计结果，而不是原始采样点。

| 数据类型 | 默认处理 | 原因 |
|---|---|---|
| GPS 轨迹坐标 | **不返回**（`strict` 层），或降精度至约 1km 网格 | 起点终点即住址 |
| 活动开始时间 | 只到日期，可选只到"上午/下午/晚间" | 精确时刻可反推作息 |
| Garmin activity ID | 不外露，内部映射为序号 | 可反查公开活动页 |
| 用户 ID / 设备序列号 | 永不输出 | 账号与设备标识 |
| 心率、配速等时序 | 默认返回统计量（均值/最大/分位） | 低采样率即可满足分析 |
| 距离、时长、训练负荷 | 原样返回 | 无位置与身份信息 |

三档隐私级别，通过配置切换：

- `strict`（默认）：无坐标、时间粗化、无原始 ID
- `normal`：无坐标，保留精确时间与 ID
- `raw`：全字段，需显式开启，启动时打印警告

**不要依赖 AI 侧"不会乱说"来保护数据**——一旦进入上下文就已经离开了本机。脱敏只能发生在数据出来之前。

### 给提交者

fork 后开发时请确认 `.fit` 与导出 zip 没有进过提交。轨迹文件含 GPS 坐标，一旦进入公开仓库的历史，即使后续删除也仍可从旧 commit 中找回——这是 Git 的行为，与本工具无关。
